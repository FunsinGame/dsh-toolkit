# SoundDesk 功能说明

这份文档回答两个问题：**每个功能是干什么的**，以及**具体怎么用**。

- 想知道「怎么装、怎么跑起来」→ 看 `README.md` 的「快速开始」。
- 想知道「为什么这么实现」→ 看 `README.md` 的「关键实现说明」和 `PLAN.md`。
- 本文只讲**界面上看得见的东西**：哪个按钮、点了会发生什么、什么时候该用它。

两处贯穿全文的前提，先说清楚：

1. **一切都在本地。** 索引、搜索、指纹、模型推理都发生在你自己机器上，不上传任何东西。模型（CLAP 声音指纹）随 VSCode 插件离线打包，不需要联网下载。
2. **试听、效果、多轨、对比都不会改动你的音频文件。** 全流程只有两处会写文件：**导出**（写出*新*文件）和**元数据写回**（会先备份，详见 §11）。除此之外文件是只读的。

## 1. 界面总览

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部：搜索栏（搜索框 / 模式 / 个性化 / 参考音频 / 状态）          │
├──────────┬──────────────────────────────┬────────────────────┤
│ 左栏     │ 中栏：结果列表                │ 右栏：详情          │
│ 素材库   │ （永远在这里，不被别的面板顶掉） │ 技术信息/分类/标签  │
│ 播放列表 │                              │                    │
│ UCS 分类 │                              │                    │
├──────────┴──────────────────────────────┴────────────────────┤
│            ↑ 效果 / 多轨 / 对比 三个浮窗从这里弹出 ↑             │
│ 底部：播放栏（波形 / 播放控制 / 三个面板按钮）                    │
└──────────────────────────────────────────────────────────────┘
```

三个浮窗（效果 / 多轨 / 对比）都是**从播放栏往上弹**的，同一时刻只会开一个：它们占同一个位置，两个同时开会叠成一团。所以点开多轨会自动关掉效果，反之亦然。**中栏的结果列表永远在**——浮窗不会把它挤走，因为这三个面板本来就是围绕「列表里选中的那条声音」在用的。

## 2. 搜索栏

### 2.1 用法

在搜索框里**用一句话描述你要的声音**，中文即可：

```
金属门 关上
雨打在铁皮屋顶
远处的雷声
```

输入后 **260ms 自动搜索**（不用按回车），按**回车**立即搜。按 **Esc** 清空并重新搜索（回到全部素材）。

### 2.2 三种模式（同一排按钮）

| 模式 | 实际在比什么 | 什么时候用 |
| --- | --- | --- |
| **混合**（默认，推荐） | 关键词 + 声音指纹 + UCS 分类名，三路结果加权融合 | 绝大多数情况 |
| **语义** | 只比声音指纹（CLAP 向量） | 你确定「像不像」比「叫什么」更重要 |
| **关键词** | 只比文件名、内嵌元数据、UCS 分类名 + `(a, b) -c *` 语法 | 记得文件名，或要精确排除 |

**关键区别**：中文查询会被**改写成英文**再去比（因为 UCS 词表和大多数素材命名是英文）。改写结果会显示在结果列表顶部：

```
检索用 caption  metal door close  impact
未识别：哐当声
```

「未识别」的词是被丢掉的部分——如果一个词都没识别出来，大概率搜不到，换个说法即可。

> ⚠️ 换模式**不会自动重搜**。点完模式按钮，再按一下回车（或改一个字触发防抖）。

### 2.3 状态区（最右）

显示三种情形之一：索引进度 `索引进度 1200/3383`、`搜索中…`、或 `3383 条素材 · 42ms`。

### 2.4 个性化按钮

只有引擎报告了个性化数据时才出现，详见 §16。

## 3. 素材库管理（左栏最上）

### 3.1 添加本地素材库

**在 VSCode 插件里**：左栏有 `＋ 添加本地素材库` 按钮，点它选一个目录即可。

**在浏览器里**：没有这个按钮（浏览器拿不到文件夹的真实路径），改用命令行：

```bash
sounddesk --add "D:/SFX" 库名
```

### 3.2 作用是什么

添加后会走**分级索引**：先快速读元数据让素材立刻可搜，波形和声音指纹在后台慢慢补。所以刚导入完就能用关键词搜，语义搜索要等指纹补齐。

### 3.3 导入期间为什么整个界面被挡住

导入时会盖一层**全屏进度**，结束前不能操作。这是刻意的：索引到一半的库，素材数、分类计数、搜索结果全都在变，让你继续点等于让你对着即将失效的数字做决定。进度条来自引擎自己的任务事件，不会和实际进度对不上。完成后变成一个可关闭的汇总卡，点掉即可。

### 3.4 两个按钮的区别（很容易搞错）

| 按钮 | 干什么 | 什么时候点 |
| --- | --- | --- |
| **重扫** | 增量重扫，**只重读元数据**，很快 | 你往目录里加了文件 |
| **补齐指纹** | 额外重建波形 + 计算声音指纹，**比较久** | 语义搜索/以声搜声搜不出东西，或状态显示指纹数 < 素材数 |

「补齐指纹」只在**指纹确实不齐**时才出现，是断点续传的：已经算过的不重算，中途关掉下次接着来。

### 3.5 左栏底部的三个数字

- `索引库` —— catalog.db 的大小。
- `声音指纹 3383/3383` —— 有多少素材有指纹。左边小于右边，语义搜索就只用了一部分素材。
- `波形缓存` —— 已缓存的波形数量（决定试听时波形出得多快）。

## 4. UCS 分类树（左栏最下）

### 4.1 它是什么

UCS（Universal Category System）是影视音频行业的**官方分类词表**，本工具内置 **v8.2.1 正式版：82 个大类 / 753 个 CatID**（数据文件带 SHA-256 校验，未做任何自造）。

### 4.2 怎么用

- 点大类（如 `DOOR`）→ **筛选出这一类**，同时展开子类。
- 点子类（如 `DOORWood`）→ 精确筛选。
- 点 `全部` → 取消分类筛选。
- 上面的 `过滤分类…` 输入框是**筛这个树本身**（找类名），不是搜素材。

**重要**：选分类是**对当前搜索的收窄**，不是切换到浏览模式。心智模型只有一个——永远有一个查询，树只是把结果变窄。所以你可以「搜『门』+ 只看 DOORWood」。

### 4.3 计数怎么读

每个分类后面的数字是**该分类下的素材数**。空分类默认不显示（不然三十多个空类会把有内容的几个埋掉）。底部 `2418 条未分类` 告诉你还有多少素材没能归入任何 CatID——没归类的素材**不会**出现在任何分类筛选里。

## 5. 搜索结果列表（中栏）

### 5.1 每一行在说什么

```
★ 大教堂_门_02.wav          DOORWood  金属感       ▍关键词
  1.8s  48kHz  2ch
```

- **★** —— 已收藏。
- **文件名** + 灰色的是相对目录。
- **CatID 徽标** —— 分类结果。**它按可信度着色**：绿色=文件名/元数据直出，黄色=推断，灰色=低置信。悬停看来源。
- **未分类** —— 这条没能自动归类。
- **标签** —— 你自己的标签（最多显示 3 个）。
- **右侧竖线** —— 匹配度，悬停看「匹配度 87%」和**排序依据**逐条列出。
- **关键词/语义/…** —— 这条是被哪一路检索召回的。绿色表示重排时有词命中。
- **@128** —— 窗口命中（见下），意思是「文件里第 128 个分析窗和参考音频相似」。

### 5.2 交互

| 操作 | 结果 |
| --- | --- |
| 单击 | 选中，右栏显示详情 |
| 双击 | 试听 |
| 拖拽 | 带出下载地址（可拖到 DAW / 桌面），详见 §19 |

### 5.3 顶部提示条的含义

- **`语义指纹还没补齐…`** —— 后台在算指纹，现在只用了文件名/元数据/分类，补完语义自动生效。
- **`没有足够接近的结果——这本身是信息`** —— 不是出错，是库里可能真没有像的。
- **`没有结果`** —— 会**分情况**给建议：如果你在关键词模式且库里已有指纹，会直接给一个「改用语义搜索试试」按钮；如果模型没加载，会明确说「语义搜索当前不可用」而不是让你白改查询。

## 6. 详情面板（右栏）

选中一条素材后，从上到下：

### 6.1 文件与操作

`试听`、`找相似`（以声搜声，见 §8）、`☆ 收藏`、`下载`（下载原始文件，文件名不变）、`在系统中显示`、`编辑器打开`。后两个只在地面宿主支持时出现（VSCode 里有，浏览器里没有）。

同样功能的两个入口别混淆：**下载**是稳定拿到文件的方式；**拖拽**是把地址递出去（§19）。

### 6.2 排序依据

把「为什么这条排在前面」拆成可读的句子，例如：

```
文件名/元数据命中「door」
UCS 分类 DOORWood 与查询匹配
声音指纹相似度 0.71
```

**没列出来的信号说明它对该结果没有倾向**——这也是信息。

### 6.3 技术信息 / 声学特征

- 技术信息：时长、编码、采样率、位深、声道、文件大小。
- 声学特征：峰值 dB、RMS dB、衰减时间、谱质心、高频占比、调性。这些是自动分类用的**证据**，也可用来判断素材「是不是太安静/太闷」。

### 6.4 UCS 分类（可审计 + 可订正）

- 显示当前 CatID、**来源**（文件名 / 内嵌元数据 / AI 零样本 / 声学规则 / 人工）和置信度。
- **备选**列出 2–3 个候选分类及各自证据——你能看到它纠结在哪。
- `重跑分类看候选` —— 现场重新跑一遍分类流水线，列出最多 6 个候选（各自带证据与百分比），**点任意一个才会采纳**；它自己不会改任何东西。
- 或在输入框填 CatID（如 `DOORWood`）点 `订正`。

> 手动订正后，写入来源会变成 `人工`，**自动分类不会再覆盖它**。

### 6.5 我的标签

回车添加，点标签上的 `×` 移除。标签存在**旁挂数据**里，**不会写进音频文件**。

## 7. 播放与波形（底部播放栏）

### 7.1 波形交互

- **单击波形** —— 跳到该时间点。
- **拖出一段** —— 建立**选区**，播放栏会显示 `选区 0.42s–1.10s`。
- 选区有什么用：循环时只在选区内循环（做无缝素材时很关键）；`搜选区` 用这一段去找相似的（§8）；配合效果链反复试听同一小段。

### 7.2 控制按钮

| 按钮 | 作用 | 说明 |
| --- | --- | --- |
| ▶ / ⏸ | 播放 / 暂停 | 空格键同效 |
| ⏮ | 回到开头 | |
| ↻ | 循环 | 有选区时只循环选区 |
| ⇄ | 倒放 | 找反向素材或做效果时很有用 |
| 速度 | 0.25×–2× | **磁带式**：速度和音高一起变，不是时间拉伸 |
| 音量 | 0–1 | 试听音量 |
| 效果 / 多轨 / 对比 | 开关对应浮窗 | 见 §9 |

快捷键：**空格**播放/暂停，**Esc** 清除选区（在输入框里按 Esc 不触发，避免误操作）。

## 8. 以声搜声（Query by Example）

入口在顶部搜索栏右侧，**两种输入**：

### 8.1 拖入参考音频

把一个外部音频文件拖到 `拖入参考音频` 区域（或点它选文件），**上限 60 秒**。适合「我手上有个参考，帮我在库里找像的」。

### 8.2 搜选区

先在波形上拖出一段，再点 `搜选区`。适合「这条素材里这一下有戏，库里还有没有类似的」。

### 8.3 搜完之后你会看到什么

搜索栏会显示参考音频的**体检报告**：`选区搜索` 标签、时长、声道数、**峰值**，以及来自参考本身的警告。这是刻意的——「没搜到好结果」十次里有八次是「参考音频是静音的」或「参考只有 80 毫秒」，而空列表完全看不出这一点。

### 8.4 长文件切窗（max-sim）

库里那些**十分钟的环境音**，整段求平均去比是没有意义的。所以参考音频会与长文件的**每个分析窗**逐一比对，取最高分：

- 列表里命中的行会显示 `@128`，即第 128 个窗（`@` 后面的数字就是**时间位置**，直接拖到那里听）。
- 搜索栏显示 `长文件切窗：现场分析 3 个`、`窗口命中 12`。悬停能看到完整分账：多少用了已存向量、多少本次现场分析、多少太短不需要切窗、多少因超出本查询预算而跳过。
- 现场分析有**预算上限**（每个文件最多比若干窗），所以是「够用就停」而不是无限慢下去。

> 这个功能比关键词搜索慢，慢的原因会自己说出来，而不是让你觉得卡。

## 9. 三个浮窗的共同用法

**效果 / 多轨 / 对比**都是从播放栏上方弹出的窗口，共用一套规则：

1. **点按钮开，再点同一个按钮关**（三个按钮互斥，开了这个就关了那个）。
2. 每个浮窗**右上角都有 `关闭`**，作用与再点按钮相同。
3. **内容放不下就在窗口里滚动**，不会撑破或超出屏幕。
4. **关闭不等于丢弃**：所有设置都保留，重新打开还在。
5. **打开的浮窗不会挤走结果列表**：中栏永远是你在用的列表。

三个按钮上的小标记：

| 按钮 | 标记 | 含义 |
| --- | --- | --- |
| 效果 | 后面的 `•` | **你正在听到的是处理过的声音**（不是「参数改过」——面板里旁通了就不显示） |
| 多轨 | 后面的数字 | 当前有几条轨道 |
| 对比 | 后面的数字 | 当前有几栏 |

## 10. 效果链（浮窗「效果」）

### 10.1 最容易被误解的一点

**这个浮窗的开 = 效果是否作用于试听。**

- 打开 → 效果链启用，你听到的是处理后的声音。
- 关闭 → 效果**旁通**，听到原声，**所有参数保留**。

所以标准工作流是：打开 → 调 → 听 → 关掉听原声对比 → 再打开接着调。浮窗右上角随时显示当前状态：`原声` / `已修改` / `已旁通`。

### 10.2 八个模块

每个模块左侧有**开关**，关掉的模块不参与运算；每个滑杆**双击即复位**。

| 分组 | 模块 | 参数 |
| --- | --- | --- |
| 总 | 总混合 / 输出增益 | 干湿比、输出电平 |
| EQ | 低切、低频搁架、中频、高频搁架 | 增益（±24 dB）、频率（20 Hz–20 kHz） |
| 失真 | 饱和 / 过载 | 驱动、干湿 |
| 混响 | 空间 | 空间预设、衰减（0.2–8 s）、干湿 |
| 距离 | 远近 | 距离量（高频滚降 + 直达/混响比） |
| 包络 | 起止淡入淡出（ADSR） | 起音、衰减、延持、释音，**在素材时长内生效** |
| 工具栏 | 旁通 / 复位 / 预设 | |

「距离」是让一条近景素材听起来像远场的最快手段；「包络」用来削掉素材头尾的杂音或做渐入渐出。

### 10.3 预设与复位

`预设…` 下拉套用整链（如「远处闷响」「近距离金属」）。`复位` 把所有参数恢复为原声。`旁通` 是面板内部的总开关（与关闭浮窗效果相同，但浮窗留着）。

### 10.4 用它编辑多轨里某条轨道的链

在多轨浮窗里点某轨的 `效果`，这个浮窗会切过去编辑**那条轨道自己的链**（标题会写 `效果链 · 轨道「…」`），并给一个「改回编辑试听链」的入口。

### 10.5 导出

`导出` 用**与试听完全相同的音频节点**离线渲染成一个**新文件**：

- 文件名加 `_fx` 后缀；
- **已存在的文件绝不覆盖**，会自动改名；
- 页面下方 `查看已导出文件` 列出本工具导出过的文件（只认带 `_fx` 标记的），可一键删除。

## 11. 元数据写回（唯一会碰原文件的编辑功能）

这是全工具**唯一写进你音频文件本身**的地方，所以设计得很啰嗦：

1. **只对 WAV / BWF 开放**（其他格式引擎直接拒绝，并说明原因，而不是把入口藏起来）。
2. 保存要走两步：`保存到文件…` → 弹出确认框列出**具体哪些字段变了** → `确认写入`。
3. 引擎在**第一次写入前自动备份**，旁边有 `从备份恢复` 按钮，所以是可逆的。
4. 引擎的警告（如「没有 bext 块，改写到了 iXML」）会**显示出来**而不是吞掉。

可编辑字段：描述、关键词、设计师、录音师、素材库、版权、场次、镜次、备注。这些写进文件的 BWF/iXML 元数据块，能被其他专业工具读到——这也是让素材库对外可用的关键一步。

## 12. 多轨叠层（浮窗「多轨」）

### 12.1 干什么用

把多条素材**叠起来试听**：验证两个声音合不合、做层次（底噪 + 主体 + 点缀）、或先在这里配好再导出。

### 12.2 用法

1. 在结果列表里选中一条素材。
2. 打开多轨浮窗，点 `加入多轨`（最多 **4 轨**）。
3. 新轨的**起始位置默认错开**（`顺序错开` / `部分重叠` / `全部齐发` 可选）。这是刻意的：四条声音同时从 0 秒开始是一堵噪音墙，挨个听才分得清。
4. `▶ 混音` 试听整体，`总音量` 调总输出，`清空` 全部移除。

### 12.3 每条轨道能调什么

| 控件 | 作用 |
| --- | --- |
| `M` / `S` | 静音 / 独奏 |
| `效果` | 打开效果浮窗编辑**这条轨道自己的链** |
| `✕` | 移除这条轨道（不动文件） |
| 音量 / 声像 / 起始 | 单轨音量、左右声像（双击回中）、在混音里的起始秒数 |
| `复制当前效果链` | 把试听链整套复制到这条轨道 |
| 行下方 `原始 3.2s · 效果已旁通` | 该轨原始时长与链状态 |

### 12.4 导出

`多轨导出` 提供两种：

- **混音** —— 所有轨道渲染成一个文件（听到什么就导出什么）。
- **分轨** —— 每轨一个文件（拖进 DAW 继续做）。

同为 `_fx` 命名规则，**绝不覆盖已有文件**。

## 13. 多栏对比（浮窗「对比」）

### 13.1 它回答什么问题

单栏列表回答不了的那个：**换几种说法搜，找到的是不是同一批素材？**

- **跨栏重合**：几个查询都找到的素材会被标上 `●`，那是被多个描述互相佐证的；只被一个查询找到的，是那个查询的专属答案。
- **每栏独立排序**：一栏按相关度、另一栏按时长，因为「哪个最像」和「哪个最短」都是真问题。

### 13.2 用法

1. 点播放栏的 `对比` 打开浮窗。
2. 在多行输入框里**每行写一个查询**（最多 **6** 个）：

   ```
   金属门 关上
   metal door close
   door slam heavy
   ```
3. 点 `对比`（或 **Ctrl+Enter**）。每行变成一栏，搜索**顺序执行**（共用同一个引擎，并行只会让每栏的耗时失去意义）。
4. 每栏的查询框可单独改，**回车重搜该栏**。
5. 右侧 `↗` —— 用这一栏的查询回到主列表（浮窗自动关闭，因为结果已经回到后面的列表里）；`✕` 移除该栏；`📌` 钉住。

### 13.3 钉住（pin）

钉住 = **重新对比时保留这一栏的现有结果**。用途：把一个满意的结果集冻住当参照，然后拿别的查询去试，不必担心它被冲掉。栏宽也可以拖（6px 把手）。

### 13.4 和其他面板的区别

对比浮窗里点结果的行为与主列表一致（单击选中、双击试听），所以对比完可以直接在详情面板里继续处理那条素材。

## 14. 播放列表（左栏中段）

### 14.1 用法

- **新建**：在 `新建播放列表…` 输入名字回车。
- **打开/收起**：点列表名。
- **加入素材**：先在结果里选中，打开播放列表，点 `加入选中素材`。
- **排序**：每项后面的 `↑ ↓` 按钮（250px 宽的列表里拖拽太难点，按钮明确且能用键盘）。
- **移除**：`✕`（只从列表移除，**不删文件**）。
- **重命名 / 删除列表**：`✎` / `✕`。删除列表会先确认，并明确告知**素材文件不会被删**。

### 14.2 导出 M3U

`导出 M3U` 下载一个 M3U8 文件，**按原位引用你的文件**（不复制音频），可直接拖进 DAW 或播放器。适合「把这一串交给同事/继续在 DAW 里编」。

## 15. 备份与导入（左栏中段底部）

### 15.1 备份的是什么（最容易误解的地方）

**只备份旁挂数据**：标签、收藏、评级、手动分类、播放列表、使用记录。

**不含音频文件**——文件本来就在你的库里，没必要也不应该复制一份。

界面上的这句话是刻意写死的，因为「以为是完整备份，恢复时才发现只有标注」是很糟的体验。

### 15.2 导入流程

1. 勾选是否 `含搜索历史与使用记录`。
2. `导出备份` 下载 JSON；或 `导入备份…` 选一个之前导出的 JSON。
3. **先出匹配报告，再写任何东西**：

   ```
   将导入 backup-2026-09-25.json
   可匹配 3204 条
   内容哈希 3100 · 路径 96 · 文件名+大小 8
   未匹配 179 条（例如 老项目/门_03.wav、temp_01.wav）
   因标识重复被跳过 3 条
   ```

   **按什么匹配决定了可信度**：内容哈希最可信（文件改名/移动也能对上），路径次之，文件名+大小最弱。

4. 确认时二选一：`确认导入（合并）` 或 `覆盖导入`（用备份的值覆盖现有标签评级，而不是合并）。
5. 完成后给出结果汇总（应用多少条、新建多少播放列表、跳过多少条）。

> 「因标识重复被跳过」是刻意保守的行为：两个素材命中同一个标识时**跳过**，而不是随便挑一个把你的工作成果写错地方。

## 16. 个性化排序（搜索栏的「个性化」按钮）

### 16.1 它做什么

根据你自己的行为（选中、播放、导出、收藏、加播放列表等）学习一组轻量权重，让常用素材更容易浮上来。

### 16.2 为什么默认关闭、且处处写明上限

**搜索结果悄悄围着你的历史重塑自己，是很难建立信任的。** 所以：

- 是**显式开关**，悬停会说明它现在基于多少条素材、权重上限是多少（有界，不会把搜索带偏）。
- 只有引擎报告了个性化数据时按钮才出现。
- 可以**清空**所有学习到的记录（恢复成完全中立的排序）。

建议：先别开。等你对默认排序有意见了再开。

## 17. VSCode 插件

### 17.1 侧边栏（活动栏的 SoundDesk 图标）

自上而下：

- **引擎状态** —— 在线/离线、地址、数据目录、模型是否就绪、ffmpeg 是否可用；索引进度会在这里实时显示。
- **三个动作** —— `打开工具页面`、`添加本地素材库`、`刷新`。
- **素材库** / **播放列表** / **最近搜索** / **索引任务** —— 各自的真实计数，点素材库或播放列表节点可跳进工作台。

底部状态栏**默认不显示**（避免占用那一条），要显示就把设置 `soundDesk.showStatusBar` 打开。

### 17.2 命令面板（`Ctrl+Shift+P` → `SoundDesk:`）

| 命令 | 作用 |
| --- | --- |
| 打开工作台 | 打开完整 UI（编辑器页签） |
| 用选中的文字搜索声音 | 在编辑器里选中一段文字，直接拿去搜 |
| 添加素材库目录… | 选择目录并索引到完成 |
| 试听 | 试听选中的音频文件 |
| 以声搜声（找相似） | 用这个文件当参考去找相似的 |
| 设为参考音频 | 把它作为以声搜声的参考 |
| 加入播放列表 | 加入指定播放列表 |
| 打开播放列表 | 打开播放列表（支持 M3U/M3U8） |
| 复制文件路径 / 在文件管理器中显示 | 交给系统处理 |
| 重启本地引擎 / 显示引擎信息 | 引擎卡住时的自救入口 |
| 刷新素材库视图 | 重画侧边栏 |

### 17.3 资源管理器右键菜单（对音频文件）

对 `.wav/.bwf/.wave/.aif/.aiff/.flac/.mp3/.ogg/.m4a` 右键：`试听`、`以声搜声（找相似）`、`加入播放列表`、`设为参考音频`。

### 17.4 音频文件的自定义编辑器

双击上面这些格式的音频文件，会用 SoundDesk 的编辑器页签打开（可试听、看波形、直接在工作台里处理），而不是交给系统播放器。页签右上角有 `打开工作台`。

### 17.5 插件设置

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| `soundDesk.dataDir` | 空 = `~/.sounddesk` | 索引库、模型、波形缓存的位置 |
| `soundDesk.loadModel` | `true` | 加载 CLAP 声音指纹模型。**默认开**：模型随插件离线打包，关掉等于关掉语义搜索 |
| `soundDesk.autoStartEngine` | `true` | 激活插件时自动在插件宿主里启动本地引擎 |
| `soundDesk.openInBrowser` | `false` | 打开工作台时同时用系统浏览器打开同一地址 |
| `soundDesk.showStatusBar` | `false` | 是否占用底部状态栏 |
| `soundDesk.musicFolders` | `[]` | **预留**，目前请用「添加素材库目录…」命令 |

## 18. 搜索语法与快捷键（速查）

### 18.1 关键词模式语法

| 写法 | 含义 |
| --- | --- |
| `door` | 必须含 door |
| `door close` | 两个词都要（AND） |
| `door, close` | a 或 b（逗号是**或**） |
| `(gust*, blow*)` | 一个「或」分组；单独一个词时仍是 AND |
| `-window` | 排除 window |
| `-(a, b)` | 排除整组 |
| `gust*` | 前缀匹配（`*` 只能放结尾） |

例：`wind (gust*, blow*) -window` = 「必须有 wind，另外尽量带 gust 或 blow 开头，但不要 window」。

> 注意逗号：`金属门 关上` 是「两个都要」，`金属门, 关上` 是「哪个都行」。

### 18.2 快捷键

| 按键 | 作用 |
| --- | --- |
| `Enter` | 立即搜索（搜索框里）/ 重搜该栏（对比栏里） |
| `Esc` | 清空查询并重搜；波形焦点时清除选区 |
| `空格` | 播放 / 暂停 |
| `Ctrl+Enter` | 在对比浮窗里执行批量搜索 |
| 滑杆双击 | 复位为中性值 |

## 19. 拖拽出文件

结果行可以**拖到 DAW、桌面或任何接受文件的程序**。三种载荷同时提供，接收方挑它能用的：

1. 声音文件的下载地址（最通用）；
2. 纯文本路径（本地程序最爱，能把文件直接拖出去）；
3. 文件名。

**浏览器里拖出去通常落在下载目录**（网页无法把真实文件交给系统），而**VSCode 插件里可以拿到真实路径**。所以：

- 要**可靠拿到文件** → 用详情面板的 `下载`。
- 要**在系统里定位** → 用 `在系统中显示`（仅插件）。
- 拖拽是「最方便」而非「最可靠」的路径，能力范围在详情面板里有说明。

## 20. 搜不到东西？先对照这六条

| 现象 | 真实原因 | 怎么办 |
| --- | --- | --- |
| 中文词一条都搜不到（关键词模式） | 关键词只比文件名/元数据/分类名，库里文件名是英文 | 切 **混合** 或 **语义**，或按文件名搜 |
| 语义模式也搜不到 | 模型没加载（`soundDesk.loadModel` 关闭） | 打开设置后重载窗口；状态栏会显示「语义搜索未启用」 |
| 语义模式结果很少 | 这个库还没生成声音指纹 | 左栏素材库的 **补齐指纹** |
| 有结果但都不像 | 查询太笼统（「声音」） | 拆成**对象 + 材质 + 动作**：「金属门 关上」 |
| 相关素材没出现在分类里 | 该素材**未分类** | 详情面板手动订正 CatID，或重跑分类看候选 |
| 长环境音没搜到 | 整段求平均不敏感 | 用以声搜声（§8），走到 `@时间` 那一窗去听 |

另外：**换模式后要重新搜一次**（改一个字或按回车），这个坑很常见。

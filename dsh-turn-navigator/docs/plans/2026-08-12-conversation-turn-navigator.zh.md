# 会话轮次导航实现计划

[English](2026-08-12-conversation-turn-navigator.md) | 中文

## 目标

增加一个可选的 Web UI 插件，帮助开发者在长 DSH 会话中确认位置并跳转，同时不改变会话日志或 agent loop（智能体循环）。

## 范围

在独立包中创建仅用于浏览器的插件 `@deepseek-ai/dsh-turn-navigator`。DSH 聊天视图声明一个会话作用域的单实例 slot，并在现有消息流旁渲染它。该插件为每条已结算的常规用户消息派生一个标记；标记少于 3 条时隐藏导航，用户滚动时高亮当前可见轮次，鼠标悬停或键盘聚焦时预览轮次，选择轮次时直接滚动到对应位置。

本次变更包括浅色／深色 token 样式、减少动态效果模式、中英文本地化标签、组件和插件测试、一项组装后的 Web 兼容性测试、一份外置 bundle patch、包文档，以及一篇记录 slot 契约的 Harness 功能 Agent Note。本次变更不会增加持久化、新的 Host API、新的会话事件，也不会改变非聊天视图的行为。

## 验证

运行新包测试、受影响的 ui-conversation 测试、客户端类型程序、插件打包、GUI 检查、无密钥的组装后 Web 场景、文档门禁和差异检查。报告实际运行的命令，并在评估实现时排除脏 worktree 中的无关改动。

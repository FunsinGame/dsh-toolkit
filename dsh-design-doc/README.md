# dsh-design-doc

DeepSeek Harness（DSH）插件：把**设计文档阅读器**放进左侧活动栏。顶部是页签（一个页签 = 一篇文档），正文用文档自带的目录导航，**点正文里任意一段，右侧就出现它的章节锚点、所在位置、这一节绑定的代码文件**；可以直接在右侧改，确认后写回 `.html` 源文件，或者一键把「改哪里、原来是什么、要改成什么」送进当前会话，让 AI 去做代码同步。

- 不改文档的写作规则：只改你点中的那一个元素的内容，其余字节原样保留。
- 坐标不是像素，是**章节锚点**：`job-10-2|p3` 这种，正好是 `Tools/DesignSync/design-map.json` 里用来挂代码的 key。
- 同源路由，不开新端口：文档由 DSH 自己的 Web 服务在 `/dsh-design-doc` 下托管，图片、CSS、跨册链接都照常工作。
- 打开过什么会记住：工作区目录、页签、当前页签、每篇的滚动位置，下次开 DSH 自动恢复。

## 功能

- **页签 = 一个独立工作区**：每个页签有自己的工作区目录、文档和滚动位置，改 A 页签的工作区不影响 B 页签。`+` 开一个空页签（沿用当前页签的工作区，可再改），空页签里列着该工作区的所有文档，点一篇就开在**当前**页签；在一个页签里点文档内的任何链接都留在该页签，不会越点越多；`×` 关掉。页签多了横向滚动。
- **后退 / 前进**：顶栏 `←` `→`（或 `Alt+←` / `Alt+→`）按页签各自的历史走，回到某一页会连**当时的滚动位置**一起恢复；新开一次导航会清空前进栈，和浏览器一致。历史也持久化，重启后还能退。
- **切走再回来不丢状态**：活动栏离开时会卸载页面，插件把视图放在模块级单例里，所以页签、当前页、选中的块、编辑到一半的草稿都还在；文档本身会快速重载一次（iframe 重新挂载），并自动滚回原来的位置。
- **右键菜单**：在页面任何地方（含文档内）右键 → 「新页签显示」把当前页复制到紧挨着的新页签（同工作区、同文档、同滚动位置），适合左右对照着读；另有「刷新」「关闭当前页签」。文档里选中文字后右键仍是浏览器自带的复制菜单。
- **目录用文档自己的**：不重复造左侧树，正文自带的「目录」按钮、章节跳转、搜索都照常工作。
- **点选**：鼠标扫过正文时用虚线预览可编辑块（段落、列表项、表格单元格、小标题、公式块、提示框、只装图片的容器），点一下在右侧出坐标卡；**选中的块在正文里一直留着蓝色实线框**，改哪一段一眼能看到，保存、刷新、切走再回来都还在。
- **图片块也能点**：`<div><img></div>` 这种只有图的容器不算死区，选中后能改 `<img>` 的 src / alt / style；图是 SVG 的话，右侧会列出它的 `<text>` 文字，改完点「保存 SVG」直接写回那个 `.svg`，圆圈、连线、布局都不动。
- **敌人数据表也能改**：九幽那种表格是页面脚本按 `<tr data-stats>` 现场生成的，格子本身没有源码位置。点这一整块会打开专用面板，直接改标题行和 `data-stats` 数值，写回源文件里那行的属性；表里的技能行仍然按单元格改。
- **布局可拖**：正文占满剩余宽度（右栏默认 380，其余全给文档）；分隔条左右拖可改宽度，双击复位，宽度记在本机。
- **坐标卡**：文档、章节（`JOB-10 · 十、…` / `10.2 …`）、坐标（`job-10-2|p3`）、原文、以及 `design-map.json` 里这一节绑定的 `.cs` 文件清单。
- **编辑并写回**：右侧「文本 / HTML」两个页签，改完点「保存到源文件」，宿主只替换该元素的 innerHTML，返回改动的行；文档自动刷新并保留滚动位置。
- **冲突保护**：保存时带上「原文」，源文件已经被别人改过就返回 409，不会覆盖。
- **发送到会话**：把改动整理成一段提示词（章节锚点 + 坐标 + 原文 + 改成 + 关联代码），并附上 `build_docs.py` 与 `map.py status` 的完整命令、明确要求 AI **自己执行收尾**，不写在「提醒用户去跑」。插进当前会话的输入框，按回车发送；插入失败时自动退回复制到剪贴板。
- **生成派生层**：一键跑 `scripts/build_docs.py`，把 md 镜像、检索索引、目录、统计重新生成。

## 安装

```powershell
dsh plugin --profile desktop add C:/g-workspace/deepseek-harness/dsh-toolkit/dsh-design-doc
```

（`add` 会把包名写进 profile 的 `dsh.profile.bundles`；如果没写进去，手工在 `~/.dsh/profiles/<profile>/package.json` 的 `dsh.profile.bundles` 里补一行 `"dsh-design-doc"`。）

**装完必须完全退出 DSH 再打开**：宿主半侧的路由只在启动时注册，`Ctrl+R` 只刷新页面不会加载它。

## 使用

1. 点左侧活动栏的书本图标打开「设计文档」。
2. 第一次用：在「工作区」那一栏填包含 `Docs/Design` 的**工作区根目录**，回车或点「打开」。它不去猜当前会话的目录，填一次就记住。
3. 点右上角 `+` 建一个空页签，在空页签里点一篇文档；想并排看两篇就再 `+` 一个。
4. 每个页签的工作区可以不同：切换页签时上面「工作区」显示的是那个页签自己的目录，改了只影响当前页签。
5. 想把当前页复制一份并排看：右键 →「新页签显示」。
6. 正文里的「目录」按钮是文档自己的，展开后按章节跳转。
7. 点正文里的段落、单元格、标题，右侧出坐标卡。
8. 改内容 → 「保存到源文件」。正文里属于表格的改动记得同步 `data/*.json`，插件看不到那一层。
9. 需要 AI 跟着改代码 → 「发送到会话」。
10. 章节有增删、标题改过之后 → 「生成派生层」。

关掉整个 DSH 再打开，页签、每个页签的工作区、当前页、滚动位置都会回来。

## 坐标是怎么来的

宿主把 HTML 解析成带字节偏移的树，给每个可编辑元素插入 `data-dd-path`，路径规则是：

```
<scope>|<tag><n>      例如 job-10-2|p3
<scope>|.             该 id 元素本身（章节标题）
```

`<scope>` 是**它前面最近的一个 id**：`<h3 id="job-10-2">` 之后、下一个 id 之前的所有内容都算 `job-10-2` 这一节。`<n>` 是这一节里同标签的第几个。

保存时宿主重新解析文件、按同一条规则算出路径、找到那个节点的 inner 区间，只替换这一段：

```js
src.slice(0, node.openEnd) + newHtml + src.slice(node.closeStart)
```

所以一次改一段只动一行，`git diff` 不会有整篇重排。

## 文件

```
lib/host.js      宿主：解析、注入坐标、同源路由、写回、跑 build_docs
lib/client.js    浏览器：页签 + 文档 + 检查器（工作区、页签、滚动位置持久化）
lib/overlay.js   注入进文档的脚本：高亮、点击上报、放行文档自己的按钮和链接
cordis.patch.yml profile bundle 声明
scripts/         test-host / test-server / test-client / smoke-real
```

## 开发

```powershell
cd C:\g-workspace\deepseek-harness\dsh-toolkit\dsh-design-doc
node --check lib/host.js; node --check lib/client.js; node --check lib/overlay.js
node scripts/test-host.mjs      # 解析 / 坐标唯一性 / 单行 splice
node scripts/test-server.mjs    # 路由 / 写回 / 冲突 / 目录穿越
node scripts/test-client.mjs    # bundle 自注册 / 插槽注册
node scripts/smoke-real.mjs     # 直接跑真实文档库
```

改宿主半侧要重启 DSH；只改 `lib/client.js` 或 `lib/overlay.js` 刷新窗口即可。

## 边界

- **只改 HTML。** `data/*.json` 是数值真源，插件不改也不校验；改了表格数字要自己去同步。
- **位图里的字改不了。** SVG 的 `<text>` 能改（`<tspan>` 会被拍平成一行文字）；PNG / JPG 里的字是像素，只能换图。
- **工作区是手动的、按页签隔离的。** 不跟随当前会话的 cwd；每个页签自己填一次，互不影响。
- **派生层按当前页签的工作区跑。** 「生成派生层」作用于当前页签指向的那个文档库。
- **不自动生成派生层。** 保存不会自动跑 `build_docs.py`，用顶栏按钮，或让 AI 跑。
- **发送到会话只插入不提交。** 需要你自己按回车。
- **结构改动做不了。** 加章节、拆段、插新元素请直接改源文件或让 AI 改；坐标按「同节第几个同标签元素」算，前面插了元素会让后面的序号移动，这种情况靠保存时的原文校验报冲突，不会改错地方。
- **九幽模块没有代码映射。** `design-map.json` 里没有它的 `links`，坐标卡会显示「这一节还没有代码关联」。
